Read it in one line

Slack talks only to the listener. The listener streams a turn to the agent, which has no network at all — its only exit is a unix socket to the proxy, which holds every real credential.

Why the relay exists

The laptop sandbox uses pasta, which needs /dev/net/tun. A pod running non-root with all capabilities dropped cannot have one. So the pod uses --unshare-net plus a socket — a different architecture, and a stronger one.

The name is wrong, deliberately

The agent pod is still henry-slack although it holds zero Slack tokens and cannot reach slack.com. Renaming it to henry-agent is written and committed, not yet applied.

Known gaps

Resume dies on an agent restart — /data is an emptyDir. No Go or node builds — no module cache, no node_modules in the sandbox. No tracing — langfuse hooks are stripped at build.
