# Title bank

A standing backlog of stream titles for this project. The channel is testing
*direction*, not optimizing one line — pull an unused title each stream, run it,
and log what happened. A direction only reveals itself over a run of streams.

**Every title here is evergreen** — about what the product *is*, not about what
was on the board that day. The day's work lives in the description.

## How to use this file

1. Read the bank. Propose **3 unused** titles from different angles — *unless*
   this is a `stream-start` run, where you pick **one** by rotation: the angle
   that has gone longest without a run.
2. **Tie-break:** when two angles are equally stale — which is every angle in a
   fresh bank — take the one listed **first** below. Never pick by vibe; an
   unstated tie-break is how the first three streams of a new project end up
   testing the same angle twice.
3. After the pick, move that line to **Used** with the date and angle.
4. When the numbers come back, append them to that Used line. Over time the
   winning *angle* shows up long before a winning title does.
5. Add candidates freely. Never delete a Used line — the log is the point.

## Truth rules

Clickbait is allowed. **False is not.** A claim the product itself contradicts
is the one failure that costs the channel.

- Numbers must be plausible on screen. If the title says 12, the board should be
  able to show something like 12.
- ⚠️ marks an identity claim about the user. Confirm before using it — it is
  only good clickbait while it is true.
- ❌ marks a line that already burned, with why. Never delete these.
